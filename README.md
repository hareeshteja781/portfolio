# Hareesh Teja Paruchuri Portfolio

Portfolio: https://hareeshteja.vercel.app/

A responsive personal portfolio website built with React and Vite to showcase software projects, technical skills, education, certifications, and contact information.

## Features
- Responsive portfolio layout
- Professional summary and technical skills
- Project showcase
- Education and certification sections
- Contact and resume download sections
- Theme toggle and smooth scrolling
- AOS, Typed.js, and Vanilla Tilt animations

## Featured Projects
- Hook Pulse — Distributed Webhook Gateway & Reliability Proxy
- AI Customer Support Bot & Automated Ticket Manager
  - GitHub: https://github.com/hareeshteja781/AI-Customer-Support-Bot-Ticket-management-system

## Tech Stack
- React 18
- Vite 5
- AOS
- Typed.js
- Vanilla Tilt
- Font Awesome

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Project Structure
```text
src/       React components and styles
public/    Static assets and resume
index.html

```
